# User Guides — Suzanne Hills

A technical writing portfolio sample demonstrating how I organize software instructions for end users.

## Read the sample

**[Canva user manual (PDF)](CanvaUserManualHills_watermarked.pdf)**

## Audience and purpose

The guide introduces users to working with Canva through a structured reference they can consult while using the software.

## My contribution

I authored the user manual. This sample represents my approach to organizing instructions and presenting information clearly for readers.

## What to look for

- Organization and navigation.
- Clarity of procedural instructions.
- How written guidance supports the user's task.

The PDF is the portfolio artifact; this repository is a documentation sample rather than an application codebase.
